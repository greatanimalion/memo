# 项目介绍

- 采用electron框架进行多端打包
- 前端技术架构采用React+tailwincss+Antd+zustand组合
- 后端采用express框架

# 模块介绍

1. ai辅助写作：采用noteblock渲染富文本，并集成ai写作系统，支持markdown，html，json格式的内容的导出与导入。
2. ai规划日记，后端目前写了三个工具函数，分别是时间调用函数，写日记函数，写备忘录函数，通过tools参数传递给ai，并添加system prompt约束用户提问 。
3. 所有ai相关的回答支持流式输出，允许更改全局颜色配置，该功能通过更改css变量实现。

**分析输入：** 用户说了“ok”。2. **确定语言：** 中文（尽管“ok”是通用语，但提示词明确指出了“你是一个中文 AI 助手” You are a Chinese AI assistant）。3. **确定意图：** 用户在确认、同意，或者仅仅是发起对话/测试 AI。没有具体问题。4. **构思回复：** * 礼貌地输入。* 重申已准备好提供帮助。* 保持自然且乐于助人的中文表达。* _草稿 1：_ 好，有什么我可以帮您的吗？ - _简单，标准。_ * _草稿 2：_ 好的！请问有什么我可以为您效劳的吗？ - _稍显正式。_ * _草稿 3：_ 好的！随时为您提供帮助，请问有什么需要吗？ - _友好。_
5 **选择最佳回复：** 草稿 1 或草稿 2。让我们采用一种友好、标准的问候语。“好的！请问有什么我可以帮您的？” 6. **最终润色：** “好的！请问有什么我可以帮您的吗？”好的！请问有什么我可以帮您的？
